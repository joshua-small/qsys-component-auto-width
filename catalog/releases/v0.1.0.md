Automatically fit component widths to exposed control-pin labels without changing their text. Independent successor to the width feature in Automatic Geometry.
Requires Mods Core 0.1.7 or later within 0.1.x. Replace legacy Automatic Geometry as a grouped Mod Manager profile change; historical packages remain available for rollback. Initialization details are in Preferences > Mod Diagnostics.
Native Designer checks cover nested Container/Channel Group pin alignment, main/exposed pins, grouped undo/redo, registered commands, and snap-target registration. Physical drag/key input and connected-wire coverage remain limited; no DSP/hardware claim.
